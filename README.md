# Smart Building

The building-technology strand of chAIn: a cloud control plane plus, from stage SB2, an edge
gateway per property. It registers the devices of a hotel, models rooms as digital twins, runs
rules such as "window open → heating off", and exchanges occupancy and faults with the Hotel OS.

Prototype status: built and accepted against simulators only; nothing runs in a hotel yet.
